# Property-based Testing Reference

The `prop` DSL, `forall` engine, and `gen` generator factories are exported from `'utest'`.

```js
import { prop, forall, gen, is_generator } from 'utest';
```

---

## Testing APIs

### `prop(name, generator, prop_fn, opts)`

Registers a property test block. Equivalent to wrapping `forall` inside an `it` block.

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `name` | string | The name of the property test. |
| `generator` | Generator | The generator defining the input data shape. |
| `prop_fn` | function | The property assertion function `(value, ctx)`. Must throw/assert on failure. |
| `opts` | object | Optional configuration. See Options below. |

### `forall(generator, prop_fn, opts)`

The core property testing engine. Can be called directly if you wish to run property tests outside the standard `prop()` block definition. 

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `generator` | Generator | The generator defining the input data shape. |
| `prop_fn` | function | The property assertion function `(value, ctx)`. Must throw/assert on failure. |
| `opts` | object | Optional configuration. See Options below. |

### Options

| Key | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `runs` | integer | `100` | The number of random inputs to test before considering the property successful. |
| `shrink_max` | integer | `500` | The maximum number of shrinking steps to attempt when finding a minimal counterexample. |
| `seed` | integer | (random) | Hardcode a random seed. Useful for reproducing CI failures. |
| `persist` | boolean | `true` | Whether to automatically persist and replay failing counterexamples locally. |

## Generators

All generators are available under the `gen` object.

### Primitives

- `gen.int(lo, hi)`: Generates an integer uniformly distributed in the range `[lo, hi]` inclusive.
- `gen.bool()`: Generates `true` or `false`.
- `gen.float(lo, hi, opts)`: Generates a floating point number in `[lo, hi]`. `opts.precision` controls the discrete steps (default `10000`).
- `gen.constant(v)`: Always yields the exact value `v`.
- `gen.elements(v1, v2, ...)`: Uniformly picks one of the provided values.

### Strings

The `opts` object for strings requires either `{ len }` for an exact length or `{ min_len, max_len }` for bounds.

- `gen.string(opts)`: Generates strings from `opts.charset`. The default charset includes lowercase letters, numbers, and space.
- `gen.ascii(opts)`: Generates strings using all printable ASCII characters.
- `gen.alphanumeric(opts)`: Generates strings using `[A-Za-z0-z]`.

### Collections

The `opts` object for arrays requires either `{ len }` for an exact length or `{ min_len, max_len }` for bounds.

- `gen.array(elem_generator, opts)`: Generates arrays where every element is produced by `elem_generator`.
- `gen.tuple(gen1, gen2, ...)`: Generates a fixed-size array where index `i` is generated by `gen[i]`.
- `gen.record({ k1: gen1, k2: gen2 })`: Generates an object matching the shape of the specification.

### Combinators

- `gen.oneof(gen1, gen2, ...)`: Uniformly delegates to one of the provided generators.
- `gen.frequency([weight1, gen1], [weight2, gen2], ...)`: Delegates to generators based on their relative weights.
- `gen.optional(generator, opts)`: Yields either `null` or a value from `generator`. `opts.none_weight` and `opts.some_weight` control the probability (both default to 1).
- `gen.map(generator, fn)`: Transforms the output of `generator` by passing it through `fn(value)`.
- `gen.bind(generator, fn)`: Passes the output of `generator` to `fn(value)`, which must return a *new* Generator to be evaluated.
- `gen.filter(generator, pred, opts)`: Discards values from `generator` that do not satisfy `pred(value)`. Throws a discard sentinel if `opts.attempts` (default `32`) consecutive failures occur.

### Utilities

- `is_generator(v)`: Returns `true` if `v` is a generator object.
